    < 2100F Vacuum System

    DP Manifold

    The high-vacuum distribution manifold on the outlet side of the diffusion pump. Distributes DP pumping capacity to the main chambers (Camera via V8, Stage via V26, Column via V10) and connects to the RP2 roughing manifold via V27. Also has an N2 vent via V35.

    Connects

    • V8 ↔ Camera
    • V9 ↔ DP
    • V10 ↔ Column Pipe
    • V26 ↔ Stage
    • V27 ↔ RP2 Manifold
    • V35 ↔ N2 Vent
